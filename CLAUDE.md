# CLAUDE.md

## Task Observer activation

At the start of any task-oriented session — any interaction where you will
use tools and produce deliverables — invoke the `task-observer` skill
(`.claude/skills/task-observer/SKILL.md`) before beginning work. This
ensures skill improvement opportunities are captured throughout the
session.

When loading any other skill, check
`.claude/skill-observations/log.md` for OPEN observations tagged to that
skill. Apply their insights to the current work, even if the skill file
hasn't been updated yet.
